Quick Reference

Step-by-step reminders for occasional admin tasks

🎓 Closing a session
  1. Student Directory → filter Status: Active + Session: Spring-YYYY
  2. Bulk Action → Set status to Alumni
  3. Export backup JSON immediately after
📬 Inviting returning students
  1. School Attributes → Sessions → check Enrollment Open for Fall-YYYY first
  2. Dashboard → "✉️ Invite returning students"
  3. Left column: uncheck anyone not returning
  4. Right column: check any Interest students to include
  5. Set expiry days → Send invitations
⚠️ Enrollment Open must be set before this button appears
🔓 Opening / closing parent portal
  1. School Attributes → Parent Portal Access toggle
  2. Turn OFF before deploying updates
  3. Turn ON after verifying the live portal
🔒 Opening / closing staff portal
  1. School Attributes → Staff Portal Access toggle
  2. Turn OFF for teacher/viewer-affecting changes
  3. Admin always gets through regardless
🚀 Deploying a portal update (index.html)
  1. Export backup JSON from portal
  2. School Attributes → disable Parent Portal Access
  3. School Attributes → disable Staff Portal Access
  4. Upload new index.html to GitHub repository
  5. Wait ~2 minutes for GitHub Pages to propagate
  6. Log in as admin on live portal and verify the change
  7. Re-enable Staff Portal Access
  8. Re-enable Parent Portal Access
⚠️ For UI-only changes (directory columns, styling) you can skip steps 2–3. Always required for intake flow changes.
💾 Restoring from backup
  1. School Attributes → Restore from backup
  2. Choose the JSON file from your Downloads or Google Drive folder
  3. Portal immediately saves restored data to Drive
🔍 Finding teacher aide volunteers
  1. Open the Drive JSON in Notepad++ or VS Code
  2. Search (Ctrl+F) for volunteer or aide
  3. Parent name appears a few lines above in the same record
Or use Student Directory search box — now searches notes fields too
📚 Updating book inventory
  1. Open inventory.html → Export Students section
  2. Select session and status (Active) → Download CSV
  3. Open Google Sheet → Students tab → paste CSV data
  4. Distributed counts update automatically via COUNTIF

FAQ & Troubleshooting

Click a question to expand the answer

Parent portal shows "enrollment closed" even though I turned it on ▼
The intakeEnabled setting is fetched from Apps Script for public users. After toggling in School Attributes, wait 1–2 minutes and ask the parent to do a hard refresh (Ctrl+Shift+R). If it still shows closed, verify the toggle is saved by checking School Attributes again.
A new staff member logs in and sees no students ▼
The portal stores data in localStorage per browser per device. Teacher role always self-initializes on login via DriveSync. Viewer role also runs DriveSync on login (fixed in current version). If a viewer still sees nothing, have them log out and log back in. If still empty, an admin logging in once on that device will seed the data.
"Invite returning students" button doesn't appear on Dashboard ▼
The button only appears when a session has Enrollment Open checked. Go to School Attributes → Sessions → find Fall-YYYY → check the Enrollment Open checkbox and save. Then return to the Dashboard.
Date of birth shows one day off in the Student Directory ▼
This was a timezone bug — JavaScript was interpreting YYYY-MM-DD dates as UTC midnight, which shifted one day back in Pacific Time. Fixed in the current version of index.html. If you see it, you may be on an older deployed version.
GitHub Pages not showing my latest changes ▼
GitHub Pages can take 1–5 minutes to propagate after a push. Do a hard refresh (Ctrl+Shift+R) to bypass browser cache. Check the Actions tab in the GitHub repository to confirm the deployment completed successfully (green checkmark).
Parent says they filled out the interest form but nothing happened ▼
Interest status is correct — it means we have their form on file. They will not receive further communication until they are moved to Invited when enrollment opens. If they return to the parent portal, they will see a message confirming we have their form.
Send Email shows no recipients ▼
Check the Status and Session filters in the Send Email modal — they default to Active + current session, which may not match your data. Try setting Session to "All sessions" or changing the Status filter. Also verify the students you expect are in the correct status in the Student Directory.
Active student logs into parent portal and sees no student info ▼
The parent portal for Active students now shows a welcome screen first with either an admin message or a quote of the day. The student info appears after clicking Continue →. If the Continue button is missing or info is blank, check the browser console (F12) for errors and confirm the student record has a valid session assignment.
How do I edit the Active Student Portal Message? ▼
Go to School Attributes → Active Student Portal Message section. Type your message (supports multiple lines), then click Save message. Leave it blank to show the daily Hindi/Indian quote instead. The message is stored in the Drive JSON and is available to all public users immediately.
How do I back up the portal data? ▼
School Attributes → Export backup — downloads the full JSON to your Downloads folder. You can also navigate to your Google Drive synced folder in the file dialog if you have Google Drive for Desktop installed. Google Drive also maintains automatic version history on the portal JSON file — right-click the file in Drive → Manage versions to restore an older copy.
